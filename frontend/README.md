# Lumen — frontend

Interface da plataforma Lumen (Next.js 16, exportada como site estático para o Firebase Hosting).

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run deploy   # next build + firebase deploy --only hosting
```

A documentação completa (arquitetura, variáveis de ambiente, deploy e segurança) está no [README principal](../README.md).
